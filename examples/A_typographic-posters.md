# Group A | Typographic Posters

## Exercise [60mins]
- Choose, analyze and describe a poster [10min].
  - In pairs of 2, choose a poster each – but don’t let your partner see it.
  - Extract the text into a text file with a bit of hierarchical context, e.g.
    - Title: _Palalalace_ | Text: _Palace St. Gallen, palace.sg_
- Describe the poster to each other [3 x 15min].
  - You each make a few versions of the described poster (e.g. w/ marker on A6/7, at least 3 versions).
  - After each version you can check with your partner, refine the description and try again.
