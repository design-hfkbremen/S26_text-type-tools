### Sketches / Wireframes [11–12:00 | 5min each]
[**Typographic Semantics**](https://www.google.com/search?q=semantische+typografie&sca_esv=1ceb3cbd30d81faa&udm=2&biw=900&bih=1038&sxsrf=ANbL-n6t7NHIFa9lmekj1ABuLBCJ2WDd9A%3A1780218751313&ei=f_sbauTdErG4i-gP1fjC4Ao&ved=0ahUKEwikma3Sl-OUAxUx3AIHHVW8EKwQ4dUDCBE&uact=5&oq=semantische+typografie&gs_lp=Egtnd3Mtd2l6LWltZyIWc2VtYW50aXNjaGUgdHlwb2dyYWZpZTIHEAAYgAQYEzIHEAAYgAQYEzIGEAAYHhgTMggQABgFGB4YE0iRH1DHB1ijHnAEeACQAQCYAUqgAaIJqgECMjK4AQPIAQD4AQGYAhqgAokKwgIGEAAYBxgewgIFEAAYgATCAgcQIxjJAhgnwgIKEAAYgAQYigUYQ8ICBBAAGB7CAgYQABgFGB6YAwCIBgGSBwIyNqAHrV6yBwIyMrgH_gnCBwcwLjE1LjExyAdKgAgB&sclient=gws-wiz-img)
1. What text is on my poster?
2. The message of the text translated into the typography would look like ...
3. My poster is a metaphor for a garden / a house / a hug / gardening / growth / conflict / collaboration ...
4. The audience of the poster is a child / me / my neighbour / someone with visual impairment / ...

**Typefaces**
1. My poster has X typeface(s).
2. The letters are in a grid / geometrical / handdrawn / stretched / ...
3. The biggest / smallest part is ...
4. The typography is loud / quiet / playful / structured / ...

**Layout**
1. The composition is balanced / gridded / chaotic / asymetrical / centered / structured / ...
2. Contrast comes from layout / size difference / color / overlay / whitespace ...
3. If my poster were music it would be staccato / crescendo / echo / techno / ...

**Interaction**
1. How can you interact with the poster (scroll, click, hover, voice, gyroscope)?
2. How does the poster change on interaction / animation (color, size, width)?
3. What’s the role of the user (explorer, navigator, reader, writer)?
