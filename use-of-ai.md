<details class="note">
  <summary class="note">Tips for using LLMs for coding support</summary>
  <ol>
    <li>Learn the basics first – without ChatGPT.
      <small>You can only evaluate generated code, if you can read and
        understand it. Try things out and make mistakes.</small>
    </li>
    <li>Learn how to debug independently.
      <small>Read documentation, search Google/Stackoverflow, ask peers, log
        & inspect. Debugging is an important skill that has to be practiced.</small>
    </li>
    <li>Ask for explanations instead of solutions.
      <small>e.g. “Explain JS loops for a five-year old.”, “Can
        you guide me step by step with questions instead of just giving me the answer?”, “Give me three
        options with pros / cons, without implementing it. ”, “Can you give me
        hints about this error code, but don’t fix my code yet?”.</small>
    </li>
    <li>Don’t blindly trust AI, reflect on bias and ethical implications.<br>
     <i>see <a href="https://www.aimyths.org/" target="_blank">[AI Myths]</a> or <a
          href="https://direct.mit.edu/books/book/4660/Data-Feminism" target="_blank">[Data Feminism –
          Catherine D'Ignazio, Lauren F. Klein]</a>.</i>
    </li>
  </ol>
</details>
